`   1q`# 🤖 Restos - Система оценки сотрудников

## 📖 Описание системы

**Restos** - это мощная Telegram-бот система для проведения комплексной оценки сотрудников организаций. Система предоставляет полный цикл управления процессом оценки: от создания организаций и сотрудников до проведения замеров, аналитики и генерации отчетов.

### 🎯 Основные возможности

#### 👥 Управление персоналом
- **Организации**: Создание и управление организациями
- **Сотрудники**: Добавление сотрудников с различными ролями (администраторы/пользователи)
- **Приглашения**: Приглашение сотрудников для совместной работы с ограниченными правами

#### 📋 Управление критериями оценки
- **Критерии**: Создание критериев оценки (текстовые, числовые, булевые)
- **Наборы критериев**: Группировка критериев в переиспользуемые наборы
- **Комбинирование**: Возможность комбинирования нескольких наборов для комплексной оценки

#### 📊 Проведение оценок
- **Замеры**: Проведение оценок сотрудников по выбранным критериям
- **Вопросы**: Автоматическая генерация вопросов на основе типа критерия
- **Комментарии**: Возможность добавления комментариев к ответам

#### 📈 Аналитика и отчеты
- **Базовая аналитика**: Статистика по критериям и средним баллам
- **ИИ-ассистент**: Продвинутая аналитика с использованием искусственного интеллекта
- **Экспорт**: Генерация отчетов в PDF и Excel форматах

## 🚀 Быстрый старт

### 📋 Подготовка системы

1. **Создайте организацию** (только администратор)
   - Перейдите в меню "Организации"
   - Создайте организацию с названием и кодом

2. **Добавьте сотрудников**
   - Создайте сотрудников через меню "Сотрудники"
   - Пригласите пользователей для совместной работы

3. **Создайте критерии оценки**
   - Перейдите в меню "Критерии и наборы"
   - Создайте критерии разных типов (Да/Нет, числа, текст)

4. **Сформируйте наборы критериев**
   - Сгруппируйте критерии в наборы
   - Установите дефолтные наборы для быстрого доступа

### 📝 Проведение оценки

1. **Начните оценку**
   - Выберите "Оценки" в главном меню
   - Выберите тип оценки

2. **Настройте параметры**
   - Выберите организацию
   - Укажите кто заполняет оценку
   - Выберите оцениваемого сотрудника

3. **Проведите замер**
   - Выберите или создайте набор критериев
   - Ответьте на автоматически сгенерированные вопросы
   - Добавьте комментарии при необходимости

4. **Получите результаты**
   - Просмотрите результаты оценки
   - Сгенерируйте PDF или Excel отчет

## 🎯 Типы пользователей

### 👑 Администратор
- Полный доступ ко всем функциям
- Управление организациями, сотрудниками, критериями
- Проведение оценок и аналитика

### 👤 Пользователь (сотрудник)
- Ограниченный доступ
- Может проводить оценки только в своей организации
- Просмотр результатов своих оценок

### 📊 Аналитик
- Доступ к аналитике и отчетам
- Может просматривать статистику по организации
